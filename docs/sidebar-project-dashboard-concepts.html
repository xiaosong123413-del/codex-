项目侧栏的三种信息架构

目标：从多个维度看一个项目的过去、现在、未来，以及可调用资源。这里先看结构，不定最终样式。

A. 视图导航型

左侧只负责切换维度。适合入口清楚、右侧承载大部分信息的产品。

项目视图 +
项目：知识库改版
  • 现在目标 / 任务 / 阻塞
  • 过去记录 / 决策 / 复盘
  • 未来路线图 / 假设
  • 资源资料 / 人 / 工具

现在

右侧显示当前维度的完整工作台。

  • 当前目标完成侧栏信息架构，降低项目理解成本。
  • 下一步行动确认入口模型，然后再定视觉密度和交互。
  • 阻塞“目录”和“推进器”的职责边界还没定。

B. 项目地图型

左侧直接展开项目全貌。适合用户需要频繁在所有材料之间跳转。

项目地图 ⚙
知识库改版
  • 现在目标、任务、行动、阻塞
  • 过去执行记录、决策、案例库
  • 未来路线图、机会、风险
  • 资源资料、工具、限制、支持方
  • 沉淀专题、复盘、模板

项目全貌

左侧是完整地图，右侧解释选中的节点。

过去

执行记录、关键决策、复盘、失败原因。

现在

目标、任务、下一步、当前阻塞。

未来

路线图、机会、风险、待验证假设。

资源

资料、人、工具、约束、可复用能力。

C. 混合驾驶舱型

上半切换维度，下半只列当前维度的关键条目。适合推进工作和回看沉淀并重。

  • 下一步行动
  • 进行中任务
  • 阻塞与风险
快速资源
  • 参考资料
  • 可用模板
